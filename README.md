# Wedding Keychain Keepsake

This is the full design and plans for the RGB LED PCB for Eric and Stephie's Aug 15th 2026 wedding. These PCBs will be distributed to guests as party favors.

### Features
* Powered by a 20mm CR2032 coin cell battery
* Controlled by the ATtiny1614 by *Microchip Technology*.
* Features 32 acrylic-diffused RGB LEDs, arranged in an 8x4 matrix, to create vivid animations.
* Animations can be cycled through with a SMD tactile button.
